# Metrik POS — توحيد الواجهة وإصلاح التقارير

## ماذا يعالج هذا التحديث؟

1. **إصلاح خطأ تقارير المبيعات على MySQL:** رسالة `SQLSTATE[42000] 1055` كانت تظهر عند تجميع `CASE` المعتمد على `sales.sold_at`. حُوّلت تجميعات الأيام إلى استعلامات فرعية تحسب `report_day` أولًا، ثم تجمع الاستعلام الخارجي حسب عمود `report_day` الناتج. التغيير يحافظ على التقويم المحلي للمؤسسة وحدود التوقيت والضريبة والمرتجعات.
2. **توحيد واجهة الصفحات الداخلية:** إضافة نظام CSS مشترك فاتح ينسّق الخلفيات والنصوص والحدود والحقول والأزرار؛ يزيل التباين الضعيف القادم من درجات slate/emerald الداكنة. السايدبار والـ navbar الموحدان يظلان موجودين.
3. **لوحة تحكم أكثر اتساقًا:** إزالة الـ navbar المكرر داخل محتوى الداشبورد وإظهار بطاقات معلومات وروابط مرتبطة بصلاحيات المستخدم وصور المعاينة المحلية.
4. **مخططات فعلية:** مخطط أعمدة المبيعات اليومية من بيانات التقرير، مقارنة مشتريات الموردين من نتائج الصفحة الحالية، مخطط قيمة تكلفة أعلى الأصناف الظاهرة، ومخطط أعمار المديونية من ملخص مستحقات العملاء. لا تستخدم هذه الرسوم أرقامًا تجريبية.
5. **تقليل تكرار التنقل:** إزالة قائمة التنقل المنفصلة من صفحة تقييم المخزون لأن الـ sidebar والـ navbar المشترَكين يقدمان التنقل بالفعل.

## طريقة التركيب

1. خذ نسخة احتياطية أو أنشئ commit قبل الدمج.
2. فك الضغط داخل `C:\laravel\metrik-pos` مع الحفاظ على المسارات واسم الملف.
3. نفّذ:

```powershell
php artisan optimize:clear
php artisan test --filter=ReportsAndExpensesTest
npm run build
```

4. افتح `/reports` مع فترة تحتوي على بيانات، وتأكد من ظهور الأرقام والمخطط والجدول، ثم غيّر الفترة والفرع واختبر مرة أخرى.
5. راجع صفحات أداء الموردين، تقييم المخزون، ومستحقات العملاء، على الكمبيوتر والموبايل.
6. امسح بيانات الموقع/Service Worker فقط إذا بقيت ملفات الواجهة القديمة في المتصفح.

## الفحوصات التي أُجريت هنا

- اجتاز `php -l` ملف `SalesReport.php`.
- اجتازت ملفات Vue المعدّلة الخمس تحليل Vue SFC وتجميع القوالب باستخدام `@vue/compiler-sfc`.
- تعذر تشغيل PHPUnit في بيئة إعداد الحزمة بسبب غياب امتداد PHP `mbstring` (`mb_split` غير معرّفة).
- تعذر تشغيل Vite هنا بسبب غياب الحزمة الاختيارية `@rollup/rollup-linux-x64-gnu` في `node_modules` المحمّلة. يلزم تشغيل `npm run build` في بيئة Windows الخاصة بالمشروع قبل النشر.

لا تُعدّل إعداد `ONLY_FULL_GROUP_BY` في MySQL ولا توقفه كحل بديل؛ الإصلاح مصمم ليعمل مع التجميع الصارم بدل إضعاف إعدادات قاعدة البيانات.
